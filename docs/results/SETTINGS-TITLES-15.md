# WM-015: 앱 설정과 메모별 직접 제목

2026-11-18. 최신 origin/main 6de91e0에서 feat/settings-and-note-titles 브랜치를 만들었다. 데스크톱에서는 기존 0.9.18 장시간 시험을 계속하며 이번 개발 버전은 0.10.0 prototype이다.

## 사용자 동작

- 메모 목록 오른쪽 위 설정, 트레이 설정, 메모 더보기 설정으로 같은 창에 접근한다. 새 메모 기본 색상·크기와 직접 실행 시 목록 표시 여부를 저장한다. 기본값은 버터/320×300/목록 표시다. 기존 메모의 색상·배치는 바꾸지 않는다.
- Windows 로그인 자동 실행은 기존 StartupService에 연결하며 실제 등록 상태를 기준으로 즉시 변경한다. 진단 모드는 등록을 변경하지 않는다.
- 메모 상단 연필·더보기·F2로 직접 제목을 설정한다. 빈 제목이면 기존처럼 본문 첫 줄을 사용한다. 본문을 바꿔도 직접 제목은 유지되며 목록·보관함·휴지통·복구 사본에 반영한다.

## 저장과 수명

- 메모 스키마 5의 Title에 저장하며 기존 1–4와 제목 필드가 없는 파일을 읽는다. 제목·본문을 함께 DPAPI로 보호하고 새 형식을 모르는 이전 앱은 읽기를 거부한다. 메모의 숨김·보관·휴지통 전환과 복구 사본 생성도 스키마 5와 제목을 유지한다.
- 제목은 최대 80 UTF-16 단위이며 줄바꿈·제어 문자·잘못된 서로게이트를 거부한다. 임시 파일 중복 판정은 제목까지 비교하므로 제목만 다른 원본을 자동 삭제하지 않는다.
- 설정은 메모 루트의 settings.json에 비민감 값만 저장한다. 조회만으로 파일을 만들지 않으며 4KiB/버전·범위·유한값·링크 경로를 검사한다. 임시 저장 후 교체·이전 설정 백업을 하고 성공 후에만 현재 설정을 갱신한다. 설정 임시 파일은 미완료 메모 목록에 섞이지 않는 확장자를 사용한다.
- 설정 저장은 작업 스레드에서 진행한다. 창이 닫힌 뒤 완료된 작업은 UI를 수정하지 않으며 일반 닫기는 저장 중 보류한다. 종료 때는 창과 트레이 이벤트를 해제한다. 제목 창도 메모 폐기 시 닫는다.

## 검증과 증거

- 별도 artifacts/settings-titles-validation 출력으로 Release 빌드 경고·오류 0. 기존 실행 파일과 실제 메모 저장 데이터는 새 개발본으로 교체하거나 변환하지 않았다.
- 자동 검사 164개 통과. 신규 8개는 제목과 본문 분리·자동 제목 복귀·입력 경계, 제목 필드 없는 구형 파일·암호화 봉투·잘못된 제목, 목록/숨김/보관/휴지통/재실행, 제목 저장 실패와 재시도, 복구 제목과 제목만 다른 임시 원본 보존, 설정 기본값/영속성/새 메모 적용, 범위/파일 잠금/손상 보존, 설정 UI 저장·진단 모드 자동 실행 비활성화를 다룬다.
- 기존 작은 목록 실패 안내 레이아웃 검사가 설정 버튼을 작업 버튼 줄에 배치했을 때 실패했다. 설정을 헤더 오른쪽으로 옮겨 기존 최소 목록 높이·버튼·안내 검사를 유지하고 통과했다.
- --crash-probe: 중단 경계 8개와 복구 ID 새 프로세스 확인 2개 시나리오 통과. 미래 형식 fixture는 스키마 6으로 옮기고 새 자동 저장·중단 fixture는 현재 형식 5를 명시하도록 갱신했다.
- --settings-render: 합성 제목/본문과 진단 설정 화면을 150%로 렌더링해 설정·제목 입력·메모 PNG를 눈으로 확인했다. Windows 창 테두리나 실제 사용자 클릭·IME 시험을 대체하지 않는다.
- 로컬 결과: artifacts/settings-titles-validation/regression.log, crash.log 및 bin/WindowsMemo.Tests/release/settings-title-renders. 원격 푸시·CI는 아직 실행하지 않았다.

## 후속

실제 한글 입력·제목 대화상자·F2·자동 실행 등록 UI, 다중 DPI와 이번 버전의 장시간 사용 검토가 남아 있다. 0.10.0으로 저장한 파일은 0.9.18에서 읽을 수 없으므로 기존 데스크톱 시험에 이번 개발본을 섞지 않는다. 계정 로그인(WM-016)과 사용자용 백업·복원(WM-017)은 요청만 기록했으며 구현·인증/서버 의존성은 추가하지 않았다.

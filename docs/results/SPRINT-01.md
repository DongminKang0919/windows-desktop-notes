검증 날짜: 2026-10-13. 대상 작업: WM-001, WM-002. 앱 버전: 0.1.0. Git 커밋은 아직 없다.

## 환경

- Windows: 실제 SDK 출력 OS Version 10.0.26200, 레지스트리 UBR 9457. 사용자 확인 Windows 11
- CPU 및 런타임: x64, Microsoft.WindowsDesktop.App 10.0.12
- SDK: 10.0.401, MSBuild 18.9.11
- Visual Studio: 설치 확인 Community 2026. 솔루션은 명령줄에서 빌드했으며 IDE 실행은 별도 미검증
- 화면 배율 및 모니터 수: 아직 기록하지 않음
- 앱은 일반 사용자 권한 manifest를 사용한다. Codex 샌드박스의 바탕화면 접근 제한 때문에 호스트 검증 및 실행 명령에 승인된 제한 밖 실행을 사용했다.

## 실제 사용자 확인

| 인수 조건 | 결과 및 근거 |
| --- | --- |
| 작업 표시줄 바탕화면 보기 및 Win+D 후 메모 유지 | 사용자 답변: 메모가 보이고 입력·서식이 동작함 |
| 부착 상태 한글 입력 및 서식 편집 | 동일 답변으로 확인 |
| 다른 프로그램 창이 메모 위에 놓임 | 후속 사용자 확인 통과 |
| Win+D 두 번 후 복원된 프로그램 뒤에 메모 배치 | 사용자 답변: 프로그램 뒤에 놓이고 아이콘 클릭도 정상 |
| 바탕화면 아이콘 클릭 | 후속 답변으로 정상 확인 |

프로그래밍 방식의 문자열 삽입은 IME 조합 시험으로 계산하지 않는다. 실제 입력은 사용자 확인을 근거로 기록한다. 이동·크기 조절과 복사·붙여넣기 전체 조합, 서로 다른 선택 범위의 서식 동작은 추가 수동 검증 대상으로 남긴다.

## 구현 방식 및 수명

탐색기 소유의 보이는 `SHELLDLL_DefView`를 찾고 `HwndSource`를 WS_CHILD로 생성한다. WPF 창을 만든 뒤 SetParent로 변경하는 방식은 사용하지 않았다. 메모 위젯만 생성·폐기하고 탐색기 소유 창을 수정하거나 파괴하지 않는다.

메모의 드래그·크기 변경은 해당 자식 창의 위치를 갱신한다. Dispose는 이동·크기 이벤트와 메시지 훅, RootVisual, HwndSource를 해제한다. 이 결과는 객체 및 창 수명의 기본 검증이며 장시간 무누수를 입증하지 않는다.

## 범위와 다음 단계

첫 스프린트의 핵심 부착·입력·서식 검증을 완료했다. WM-001 및 WM-002는 위 근거로 Done 처리한다. 저장·암호화·트레이 등 첫 제품의 나머지 요구사항은 완료하지 않았다.

- WM-003: 탐색기 재시작 및 DPI·모니터 안정성. 재시작 복구는 현재 구현되지 않아 prototype 실행 중 탐색기 재시작을 시험하지 않았다.
- WM-004 / WM-011: 암호화 저장 및 서식 왕복, 데이터 보호 검증
- WM-007 / WM-008: 여러 메모, 숨김·트레이, 휴지통
- WM-012: 반복 창 시험 및 장시간 상주, 힙·CPU·네이티브 핸들 측정

단기 수집 가능 시험을 장시간 누수 시험으로 확대 해석하지 않는다. 8시간/24시간 시험 및 변조 업데이트 검증은 미수행이다.

# WM-004E — 복구 목록의 다음 항목과 탐색 수명

2026-10-22, 0.9.6 prototype, .NET SDK 10.0.401. 기존 WPF·WinForms 트레이·DPAPI·스키마 4·사용자 저장 경로를 유지한다. [미완료 메모 복구](PENDING-04D.md)의 64개 이후 탐색을 보완한다.

## 구현

- **다음 항목**으로 최대 64개씩 앞으로 진행하고 **처음부터 확인**으로 새 탐색을 시작한다. 마지막 페이지에서는 다음 버튼을 비활성화한다. 무효 이름 때문에 빈 페이지가 되어도 남은 항목이 있으면 계속 진행할 수 있다.
- 한 요청에서 후보 메타데이터를 최대 64개 확인하고 다음 경로 1개만 미리 보관한다. 페이지를 건너뛰기 위해 처음부터 반복 열거하거나 전체 목록/이전 페이지를 누적하지 않는다. 본문은 선택한 파일 하나만 기존 제한으로 읽는다.
- Windows의 디렉터리 열거 순서를 사용하며 날짜 정렬은 페이지 내부에만 적용한다. 디렉터리가 바뀌지 않을 때 전체 후보에 중복 없이 도달함을 검증했다. 실시간 추가·삭제 중 완전한 스냅샷이나 전역 날짜 정렬은 보장하지 않는다. 새 파일이 생기면 처음부터 확인한다.
- 페이지를 바꿀 때 선택·본문·복구 입력을 지우고 이전 비동기 미리보기의 세대 번호를 무효화한다. 기존 메모·임시 파일의 수정/삭제·자동 승격은 추가하지 않는다.
- 탐색 끝·재시작·오류·창 닫기에서 열거자를 해제한다. 진행 중 파일시스템 호출이 있으면 닫기 호출은 기다리지 않고 폐기 표시 후 읽기 종료/직렬화한 후속 해제로 핸들을 정리한다. 폐기는 반복 가능하며 완료/폐기 후 열거자를 다시 만들지 않는다. 장치 자체의 지연 시간 상한은 보장하지 않는다.

## 검증

- Release 빌드 경고·오류 0. 로컬 전체 **103개 PASS**: 자동 102개 + 실제 바탕화면 비표시 호스트 1개. 이전 0.9.5의 애플리케이션 제어 차단과 달리 이번 바이너리는 실행 가능했으며 보안 정책은 변경하지 않았다.
- 실제 격리 디렉터리의 0·1·64·65·128·129개 후보를 끝까지 순회하고 중복·누락 없이 도달함과 파일 내용 불변을 확인했다.
- 계측 열거자에서 처음 65회, 다음 64회만 진행함을 확인했다. 정상 종료·중간 폐기·반복 폐기·열거 예외에서 열거자 Dispose는 한 번만 실행된다. 무효 이름 64개 뒤의 정상 후보도 선택 가능하다.
- 진행 중 열거 호출을 시험에서 멈춘 상태에서도 폐기가 즉시 반환하고, 호출을 풀면 핸들을 해제함을 확인했다. 이는 실제 저장 장치 지연을 대신하는 시험이지 모든 I/O 시간 상한의 증명은 아니다.
- UI에서 첫 64개→마지막 1개→처음부터 이동, 이전 미리보기/복구 버튼 무효화, 마지막 다음 버튼 비활성, 파일 65개 보존을 검증했다. 다음 페이지가 남은 창 20회 생성·닫기 후 약한 참조 잔존 0개를 확인했다.
- 격리 자식 프로세스 강제 종료 **8건 PASS**, 실제 잔여 중복 정리 후 별도 읽기 자식 검증도 통과했다. JSONL: `artifacts/pending-pagination-validation/bin/WindowsMemo.Tests/release/crash-probe/ad84b16c267f4598841b42972f10f33a/results.jsonl`.
- README 복구 이미지는 로컬 UI 검사에서 만든 150% 컨트롤 렌더다. 파일 SHA256: `1527ad972d90c71cbcb8ae032c5b236ce7966a99575682963fbe5d8369318199`. 직접 열어 한글·버튼 배치·읽기 전용 본문을 확인했다. 사용자 바탕화면 캡처가 아니다.
- 원격 검증은 [PR #6의 CI](https://github.com/DongminKang0919/windows-desktop-notes/pull/6/checks)에서 최종 커밋 결과를 확인한다.

```powershell
dotnet build WindowsMemo.slnx --configuration Release -p:RestoreLockedMode=true --artifacts-path artifacts/pending-pagination-validation
dotnet artifacts/pending-pagination-validation/bin/WindowsMemo.Tests/release/WindowsMemo.Tests.dll --shell-probe
dotnet artifacts/pending-pagination-validation/bin/WindowsMemo.Tests/release/WindowsMemo.Tests.dll --crash-probe
```

모든 시험 데이터는 빌드 출력 아래 GUID별 폴더에 만들었다. 사용자 메모·기존 앱·Explorer·시스템 설정은 변경하지 않았다.

## 남은 확인

실제 마우스·키보드·IME·혼합 DPI·Win+D·Explorer/절전 복귀·대규모/변경 중 디렉터리·링크/정션 조합·8/24시간 상주·설치본 검증은 별도다. 재실행 간 복구 영수증·고유 파일 보존/삭제 정책과 이전 페이지 탐색은 후속이며, 장시간 누수 부재나 무한 파일 누적 방지를 보장하지 않는다.

# WM-010B2A — 0.8.0 prototype 로컬 시험 업데이트

- 날짜: 2026-10-22
- 환경: Windows x64 10.0.26300.0, .NET SDK 10.0.401
- 상태: 구현·자동 검증 완료. 실제 설치본 업데이트·UI 클릭·새 설치 파일 생성은 미검증.

## 결과

명시적 `--update-test-source <폴더>`로 실행한 Velopack 설치본에 트레이 업데이트 메뉴를 제공한다. UpdateManager가 확인·다운로드하고, 사용자가 적용을 선택하면 모든 메모를 저장한 후 재시작을 요청한다. 기본 실행과 로그인 실행에서는 업데이트 기능을 활성화하지 않는다. 0.7.0에는 이 메뉴가 없으므로 실제 시험에는 0.8.0 이상 두 버전이 필요하다.

원격 주소와 UNC 경로를 받지 않는 로컬 시험 소스를 구현했다. 재분석 지점, 파일명 경계, 제품 ID, 정식 버전, full 패키지, SHA256 형식, 피드 1MiB/100항목과 패키지 256MiB를 검사한다. 다운로드한 바이트의 크기·SHA256을 확인하고 적용 직전 캐시도 다시 검사한다. 게시자 서명 검증과 동일 계정 파일 교체 경쟁 방어는 완료 범위가 아니다. 신뢰하는 로컬 산출물로만 시험한다.

시작 훅의 자동 적용을 끄고 저장 후 수동 적용만 제공한다. 저장·적용 인계 중 편집과 workspace 변경을 차단하며, 저장 실패나 적용 요청 예외 시 편집을 복구한다. 트레이 종료 시 서비스 취소와 이벤트 해제를 수행한다. 주기 타이머·네트워크 클라이언트·새 의존성은 추가하지 않았다. 저장 스키마 3과 기존 데이터 경로를 유지했다.

## 검증

실행 중인 기존 앱이 기본 bin의 EXE를 잠그고 있어 별도 출력 폴더로 검증했다. 기존 프로세스를 종료하거나 사용자 메모를 열지 않았다.

```powershell
dotnet build WindowsMemo.slnx --configuration Release --nologo -p:RestoreLockedMode=true --artifacts-path artifacts/update-validation
dotnet artifacts/update-validation/bin/WindowsMemo.Tests/release/WindowsMemo.Tests.dll --shell-probe
```

- Release 빌드 경고 0 / 오류 0, 잠금 복원 PASS.
- 전체 **61개 PASS**, 종료 코드 0: 기존 53개 + 업데이트 서비스·소스 7개 + workspace 저장/적용 1개.
- 확인/다운로드와 적용 분리, 저장 실패 시 적용 미호출, 오류 후 재시도, 중복 확인·적용 차단, Dispose 시 취소를 가짜 backend로 확인했다.
- 가짜 로컬 피드로 정상 복사, 경로 traversal·다른 제품·시험판·과대 크기·잘못된 해시·변조·크기 불일치·취소·잘못된 채널·잘못된 JSON 거부를 확인했다.
- 실제 workspace와 DPAPI 시험 데이터로 저장 완료 시점의 내용, 적용 callback 중 편집·생성 차단, callback 예외 후 편집 복구를 확인했다. 기존 전체 저장 실패 검증에 적용 callback 미호출 확인을 추가했다.
- 기존 폐기·수집·반복 숨김과 보이지 않는 바탕화면 호스트 검증도 통과했다. 8/24시간 안정성·Win+D·실제 IME·UI 클릭 시험은 수행하지 않았다.
- 샌드박스에서 NuGet 설정 접근과 DPAPI가 제한되어 빌드·전체 검증은 승인된 제한 밖 실행으로 완료했다. 보안 설정은 변경하지 않았다.

## 남은 작업

WM-010B2B에서 0.8.0 이상 설치본 두 버전을 준비해 실제 적용·재시작·본문/서식/위치/숨김/휴지통·로그인 설정 보존·오프라인·실패 UI·제거를 확인한다. 현재 source의 시험은 유효한 설치용 nupkg를 실제 설치한 성공 증거가 아니다. Update.exe로 인계한 이후의 실패·복구도 별도 검증한다.

공개 배포 주소·게시자 인증과 서명·메타데이터 신뢰, 자동 확인 주기·다음 정상 실행 적용, 런타임 없는 PC, 의존성 취약점 재조회와 장시간 안정성은 후속이다. 이번 작업에서 원격 게시·푸시·사용자 메모 변경·실제 로그인 Run 값 변경은 수행하지 않았다.

참조: [Velopack 연동·적용·오류 처리](https://docs.velopack.io/integrating/overview), [업데이트 소스](https://docs.velopack.io/integrating/update-sources). 고정된 1.2.161의 XML API 문서와 컴파일 결과로 API 호환성을 확인했다.

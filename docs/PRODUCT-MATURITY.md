# 실사용 제품으로 발전시키기

2026-11-19. 사용자가 요청한 완성도·성숙도 고도화의 우선순위 제안이다. 아래 세부 기능은 구현 완료나 모두 확정된 요구사항을 뜻하지 않는다.

진행: 사용자 요청으로 첫 개발 단위를 실행했다. 0.12.0에서 제목 검색·상태 필터·통합 탭·최근 삭제 실행 취소·복원 후 열기를 구현했고, 회귀 167개 및 집중 검사 11개를 통과했다. 실제 사용자 검토는 남긴다. [결과](results/NOTE-MANAGER-19.md).

## 현재 위치

0.11.0 작업본에는 편집·암호화 자동 저장·숨김·보관·휴지통·설정·제목과 공통 UI가 있다. 현재 평가는 핵심 기능을 개인 환경에서 사용할 수 있는 개발 버전이다. 설치·업데이트·사용자 백업과 일부 실제 Windows 환경 검토가 남아 있으므로 다른 사람에게 바로 배포할 완성판으로 보지는 않는다.

다음 개발은 메모를 작성하고, 나중에 찾고, 실수에서 복구하고, 앱을 업데이트하는 전체 사용 과정으로 묶는다. 통과한 검사 개수는 변경의 안전성을 확인하는 근거로 사용하고, 제품 완성도의 목표로 삼지 않는다.

## 우선순위

### 1. 메모 관리 흐름 완성

- 메모 목록·보관함·휴지통을 한 관리 화면의 탐색으로 연결한다. 현재처럼 여러 창을 오가며 위치를 기억할 필요를 줄인다.
- 우선 제목 검색과 상태 필터를 제공한다. 검색은 이미 메모리에 있는 제목을 사용하고 평문 검색 인덱스를 만들지 않는다. 전체 본문 검색은 암호화·읽기 비용·오류 처리 방식을 따로 설계한 뒤 확장한다.
- 휴지통 이동 직후 실행 취소, 복원 후 해당 메모 찾기/열기로 이어지는 동작을 제공한다.
- 검색 결과 없음과 메모가 아예 없음을 구분한다. 선택·검색·목록 전환 뒤 키보드 포커스와 선택 항목이 예측 가능하게 유지되도록 한다.
- 완료의 모습: 메모가 수십 개 있어도 작성·찾기·보관·삭제·복원을 도움말 없이 이어갈 수 있다.

### 2. 작성 경험과 동작 일관성

- 주요 작성·목록 동작에 일관된 키보드 경로와 툴팁을 제공한다. 전역 단축키는 충돌 처리와 사용자 설정을 포함해 별도로 도입한다.
- 서식 선택 상태, 접기·숨김·삭제의 의미, 저장 상태 안내를 화면 전체에서 통일한다.
- 오류 안내에는 사용자가 이어서 할 수 있는 동작을 함께 둔다. 성공 안내는 편집을 막는 대화상자보다 해당 화면 안에서 짧게 전달한다.
- 완료의 모습: 마우스와 키보드 양쪽에서 작성 흐름이 끊기지 않고 실수한 동작을 쉽게 이해하고 되돌릴 수 있다.

### 3. 사용자가 직접 지킬 수 있는 데이터

- WM-017의 사용자용 백업·복원을 구현한다. 먼저 같은 Windows 계정에서 수동 백업/검증/복원을 완성한다.
- 복원 전 현재 데이터를 보존하고, 덮어쓰기/중복 처리와 실패 후 재시도 흐름을 명확히 한다.
- 다른 PC·다른 계정 이전은 별도 범위로 설계한다. 현재 DPAPI 암호문을 복사하는 것만으로 이전이 된다고 안내하지 않는다.
- 완료의 모습: 개발자의 개입 없이 백업을 만들고 보존된 내용을 확인하며 복원할 수 있다.

### 4. 설치해서 계속 사용하는 제품

- WM-010C에 따라 고정 설치 경로·바로가기·버전 정보·새 버전 안내·저장 후 업데이트를 완성한다.
- 실제 설치본 두 버전의 업데이트와 데이터 보존을 확인한다. 개발 폴더에서 빌드하는 절차를 사용자 사용법에서 제거한다.
- 서명·게시자 신뢰, 개발 도구 없는 PC의 설치/제거와 실패 복구를 확인한다.
- 완료의 모습: 처음 쓰는 사람이 설치 파일로 시작해 이후 앱 안에서 업데이트하며 사용할 수 있다.

## 다음 개발 단위

우선 1번을 제품 흐름 개선 단위로 잡는다. 작은 순서는 **제목 검색·상태 필터 → 메모/보관함/휴지통 통합 탐색 → 삭제 실행 취소와 복원 후 이동**다. 저장 포맷 변경은 이 단위의 목적이 아니다. 계정 로그인·클라우드 동기화는 목적과 데이터 이전 설계가 확정될 때 별도로 착수한다.

각 단위는 합성 메모로 전체 사용 흐름을 시연할 수 있게 만들고, 바뀐 동작에 필요한 회귀 검사와 실제 사용 검토를 마친다. 현재 버전 장시간 기록은 병행하되 같은 검사를 반복하는 것만으로 기능 개발을 대체하지 않는다.

# 요구사항 및 첫 버전 범위

2026-10-13 사용자 답변을 반영한 개발 기준이다. 구현 완료를 의미하지 않는다.

## 확정 사항

- 사용자의 Windows 11 PC부터 검증한다. 초기 빌드 대상은 현재 확인된 x64 환경이다.
- 다른 앱 뒤에 놓이고, 작업 표시줄의 바탕화면 보기 및 Win+D 이후에도 메모가 보인다.
- 바탕화면에서 메모를 클릭해 한글과 여러 줄 내용을 편집할 수 있다.
- 굵게, 색상, 목록 등 서식을 지원한다.
- 이 PC에 자동 저장한다.
- Windows 사용자 계정 기반 암호화를 적용한다. 임시 파일과 백업도 같은 보호를 적용한다.
- 삭제한 메모는 앱의 휴지통에 보관한다.
- 메모 창을 닫으면 삭제하지 않고 숨긴다. 트레이에서 다시 열 수 있다.
- 로그인 시 자동 실행은 선택 옵션이다.
- 자동 업데이트를 지원한다. 편집 중 재시작을 피하고 데이터 보존을 검증하는 방향으로 설계한다.

## 구체화한 기본 설계

확정 요구사항을 구현하기 위한 초기 설계이며 사용 후 조정할 수 있다.

| 항목 | 기본 동작 |
| --- | --- |
| 메모 수 | 여러 메모를 독립적인 창으로 관리 |
| 서식 범위 | 굵게, 글자 색상, 글머리 기호 및 번호 목록 |
| 색상 구분 | 글자 색상은 서식 요구사항에 포함. 메모 배경색 선택은 후속 디자인 항목 |
| 새 메모 | 트레이 메뉴 또는 메모의 새 메모 버튼으로 생성 |
| 숨김 | 창의 닫기 버튼으로 숨기고 내용과 위치 유지 |
| 복원 | 메모 목록에서 숨긴 메모를 선택하여 표시 |
| 삭제 | 별도의 삭제 동작으로 앱 휴지통으로 이동 |
| 휴지통 | 복원 또는 확인 후 영구 삭제. 자동 비우기는 하지 않음 |
| 종료 | 트레이의 종료 메뉴로 실제 종료. 저장 실패가 있으면 미저장 상태 안내 및 재시도 |
| 시작 | 이전에 보이던 메모를 복원하고 숨긴 메모는 숨김 유지 |
| 자동 실행 | 기본 꺼짐. 설정에서 켜고 끌 수 있음 |
| 저장 안내 | 저장 중·저장 완료·저장 실패 상태를 구분 |

첫 검증 시제품은 메모 하나로 시작하되, 서식 편집기를 사용한다. 여러 메모와 저장은 바탕화면 부착 검증 이후 구현한다.

## 인수 조건

| ID | 시나리오 | 완료 기준 |
| --- | --- | --- |
| AC-01 | 다른 프로그램과 겹침 | 다른 앱이 메모 위에 놓임 |
| AC-02 | 바탕화면 보기 | 작업 표시줄 버튼과 Win+D 각각에서 메모가 보임 |
| AC-03 | 부착 상태 편집 | 한글 조합, 여러 줄 입력, 선택, 복사·붙여넣기가 동작함 |
| AC-04 | 창 복원 | Win+D로 다른 창을 복원하면 메모가 그 뒤에 놓임 |
| AC-05 | 서식 | 선택 영역에 굵게·글자 색상 적용, 목록 생성·해제가 가능함 |
| AC-06 | 저장 및 재실행 | 저장 완료된 본문, 서식, 창 위치·크기, 숨김 상태를 복원함 |
| AC-07 | 닫기와 숨김 | 닫아도 삭제되지 않고 메모 목록에서 다시 표시할 수 있음 |
| AC-08 | 삭제와 복원 | 휴지통 이동 및 복원 후 내용·서식을 유지함 |
| AC-09 | 저장 실패 | 완료로 표시하지 않으며 메모 내용을 유지하고 재시도할 수 있음 |
| AC-10 | 자동 실행 | 사용자가 옵션을 켜거나 끌 수 있고 로그인 결과가 설정에 따름 |
| AC-11 | 탐색기 재시작 | 내용 손실 없이 메모를 다시 부착하고 입력할 수 있음 |

AC-01~05는 첫 시제품 목표다. AC-06~11은 첫 사용 버전 목표다. 자동 실행 옵션과 복구 기능은 핵심 부착 검증 이후 추가한다.

자동 업데이트는 첫 배포 준비 단계의 요구사항이다. 부착·저장 시제품 이후 구현하며 인수 조건은 `RELEASES.md`를 따른다.

보안 기본안은 외부 붙여넣기 텍스트 제한, 일반 사용자 권한, 메모 로그·자동 전송 금지다. 적용 범위와 인수 조건은 `SECURITY.md`, 리소스 수명과 장시간 검증은 `STABILITY.md`를 따른다. 계정 기반 암호화의 다른 PC 이동·복구 기능은 아직 범위에 넣지 않는다.

## 이번 범위에 포함하지 않는 항목

클라우드 동기화, 계정, 모바일 앱, 협업, 이미지·첨부파일, 체크리스트 전용 기능, HTML 편집, 고급 검색·태그, Windows 10 및 ARM64 지원은 첫 버전 범위에 넣지 않는다. 일반 글머리 목록과 체크박스 목록은 별개의 기능이다.

## 이후 사용자가 판단할 사항

- 외형: 메모 기본 크기, 배경색, 글꼴과 서식 도구 배치. 시제품을 사용한 뒤 결정한다.
- 모니터: 현재 모니터 구성부터 검증하고 여러 배율 및 모니터 변경 지원의 범위를 정한다.
- 배포: 개인 사용을 넘어 배포할 시점에 설치 방식과 라이선스를 결정한다.
- 데이터 관리: 수동 백업·내보내기 및 백업 보관 기간은 첫 저장 기능 이후 결정한다.
